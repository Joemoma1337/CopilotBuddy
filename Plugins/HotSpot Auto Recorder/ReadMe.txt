1. Create / move the folder "HotSpot Auto Recorder" into your CopilotBuddy folder.
  1.1. Ex: C:\Users\{YOUR USER}\Documents\Copilotbuddy X.X.X>\Plugins\HotSpot Auto Recorder
2. Have your WoW client running
3. Launch Copilotbuddy.exe
4. Check the box next to "Enhanced Mode"
5. Click on "Plugins"
  5.1. If the plugin does not already show, click "Recompile All"
Note: If it STILL does not show... honestly i'm not sure, those are the exact steps I've done so far
6. Check the box next to "HotSpot Auto Recorder"
7. Set Copilotbuddy to use the "Party Bot"
8. Open "Bot Config" (under enhanced settings)
9. uncheck everything and check "Do Nothing (Leader)"
  9.1 This gives you a bot that will do nothing (not gather, not combat) and allows you to roam freely to set your route)
10. Click "Start"
11. Run your route
12. Click "Stop"
Note: The log box SHOULD output the directory that the output file is saved to.

You should now have a list of hotspots to put into a Profile.
